## 国内卡为什么总在付款这一步被拒

最直接的原因：官方收银台不收银联，这一条就堵住了大部分国内银行卡。

手里有双币 Visa 也不保险，常见的失败原因有三个：卡没开通国际支付功能——很多国内信用卡的默认状态就是关着的；美元结算产生的货币转换费让部分银行直接风控拦截；还有些银行对跨境交易审核严格，支付在银行那一端就被拒了。

付款这关过了，注册环节还有坎：手机验证需要支持地区的号码，部分地区 IP 无法注册，KYC 可能要求外国证件。这些和支付是两回事，但同样会卡住人，提前有个预期。
